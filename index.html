🚀 Cara Upload ke GitHub Pages:

  1. Buat sebuah repositori baru bernama kpi-sales-2026 di akun GitHub Anda.
  2. Ekstrak isi dari file ZIP ini dan upload semua file langsung ke dalam repositori tersebut.
  3. Buka tab Settings di GitHub -> pilih menu Pages di bagian kiri.
  4. Ubah Source branch menjadi main atau master, lalu klik Save.
  5. Tunggu 1 menit dan website Anda akan tayang secara publik dan gratis!

📦 Catatan Pengolahan File:

Aplikasi ini berjalan 100% di browser pengguna tanpa memerlukan database eksternal ataupun hosting berbayar. Algoritma internal akan mendeteksi baris gabungan teks seperti "1467883-LEO WALDI" secara otomatis, memisahkan ID dengan Nama secara rapi, serta mencocokkannya dengan database divisi dan SPV Anda apabila sheet tersebut disediakan di dalam file Excel yang sama.
